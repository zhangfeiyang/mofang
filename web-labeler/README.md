# Cube Mark 标注工具

```bash
./scripts/extract_frames.sh 2
cd web-labeler && python3 -m http.server 8080
```

在浏览器打开 `http://localhost:8080`。导入方式：

- **选择图片**：一次选中多张图片，可重复追加
- **导入文件夹**：选中 `frames/视频名/` 整夹批量加载
- 把图片或文件夹拖到画布区域（支持目录递归）
- 已有列表时继续导入会追加并跳过重复文件；需要重来时用「用新文件夹替换列表」或「清空图片列表」

标注是**任意四边形**（四个角可独立拖动，不要求和画面长宽平行），适合透视下的魔方面：

- 拖动鼠标画出初始四边形，再把四个角拉到贴纸外沿
- 或连续点击四个角点；`Esc` 取消，`Backspace` 撤掉上一个点
- 选中后拖内部可整体移动，拖边上的小方块可平移整条边
- 每帧最多 3 个四边形，也可以一帧不标

导出的 `cube_annotations.json` 格式为 `cube-mark/v2`：每个标注含 `quad_xy`（从最靠近左上的角起顺时针四个像素点）以及外接矩形 `bbox_xywh`。

快捷键：左右方向键切换帧；`Delete` / `Backspace` 删除当前选中框；`Esc` 取消正在点的四边形。
